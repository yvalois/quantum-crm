# Definicion de terminado directa

Un cambio esta terminado cuando lo que el propietario solicito funciona en el VPS o en la ruta indicada y se le comunica claramente donde verlo.

Solo se valida lo solicitado y el minimo inevitable para no dañar datos, accesos, aislamiento entre perfiles, secretos o el VPS. No se exigen por defecto pruebas amplias, cobertura, CI, documentación extensa ni refinamientos ajenos.

La definición detallada anterior se conserva como referencia historica en [archivo](../99-archivo/2026-10-18/definicion-de-terminado-detallada.md).
